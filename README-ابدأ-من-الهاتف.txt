GlobalMegaStore — تجهيز APK من الهاتف فقط

محتويات هذا الأرشيف:
- مجلد GlobalMegaStore-Android: مشروع Android كامل.
- مجلد .github/workflows: تعليمات GitHub Actions لبناء APK تلقائياً.

الخطوات:
1) نزّل هذا ZIP إلى هاتفك واستخرجه باستخدام مدير الملفات.
2) افتح github.com وسجّل الدخول إلى حسابك.
3) أنشئ مستودعاً جديداً باسم GlobalMegaStore. يمكن جعله Private.
4) من المستودع اختر Add file ثم Upload files.
5) ارفع محتويات المجلد المستخرج كلها إلى جذر المستودع، مع الحفاظ على المجلدات كما هي. مهم جداً: ارفع مجلد .github أيضاً، وداخله workflows/build-apk.yml. إذا لم يظهر .github في مدير الملفات، فعّل إظهار الملفات المخفية.
6) اضغط Commit changes وانتظر اكتمال الرفع.
7) افتح تبويب Actions في المستودع. اختر Build GlobalMegaStore APK ثم Run workflow.
8) انتظر حتى يصبح التشغيل أخضر (Success). افتح التشغيل ثم قسم Artifacts ونزّل GlobalMegaStore-debug-APK.
9) استخرج ملف ZIP الذي نزّلته، وستجد app-debug.apk. افتحه للتثبيت، وقد يطلب Android السماح بالتثبيت من هذا المصدر.

ملاحظات مهمة:
- لا ترفع ملف ZIP الخارجي وحده؛ يجب استخراج محتوياته ورفع الملفات والمجلدات إلى المستودع.
- إذا لم يظهر تبويب Actions أو طلب GitHub تفعيل Actions، فعّله للمستودع ثم أعد تشغيل workflow.
- هذا يبني APK تجريبياً من نوع Debug. لم يتم تأكيد نجاح البناء على حساب GitHub الخاص بك بعد.
- AdMob يستخدم معرفات الاختبار. لا تنقر على إعلانات الاختبار ولا تتوقع منها أرباحاً.
- قبل النشر العام، استبدل معرفات الاختبار بمعرفات تطبيقك ووحداتك الإعلانية، واضبط موافقة الخصوصية وسياسات Google.
- لا تشارك كلمة مرور GitHub أو رموز التحقق مع أي شخص.

GlobalMegaStore - مشروع Android Studio

تنبيه: هذا مجلد مصدر Android وليس ملف APK جاهزاً للتثبيت.

لبناء APK:
1) انقل مجلد GlobalMegaStore-Android إلى كمبيوتر.
2) ثبّت Android Studio وافتح المجلد عبر File > Open.
3) انتظر Gradle Sync وثبّت Android SDK Platform 35 عند الطلب.
4) اختر Build > Build Bundle(s) / APK(s) > Build APK(s).
5) بعد نجاح البناء اختر Locate، ثم انقل app-debug.apk إلى هاتف Android.
6) افتح APK على الهاتف واسمح بالتثبيت من هذا المصدر عند الطلب.

ملاحظة: واجهة المتجر المضمّنة نموذج تجريبي؛ تسجيل الدخول والدفع والطلبات الحقيقية وخدمات الذكاء الاصطناعي تحتاج خادماً وربطاً لاحقاً.
